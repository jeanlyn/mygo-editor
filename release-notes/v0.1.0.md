首个预览版本，基于 MyGo 的原生桌面代码编辑器。

- 项目树、多标签、语法高亮、查找/替换、撤销/重做与基本编辑。
- 文件保存冲突检测、未保存修改关闭确认。
- 修复跨平台目录树测试及 Windows 权限测试，三平台 CI 构建。

下载：Windows x64 选择 zip；Apple Silicon 选择 macos-arm64.tar.gz；Intel Mac 选择 macos-amd64.tar.gz。解压后运行程序，SHA256SUMS.txt 可校验下载。第三方许可证随包附带。
